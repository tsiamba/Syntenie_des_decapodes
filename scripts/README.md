# Scripts

Ce dossier contient les scripts utilisés pour les analyses BUSCO et les dot plots.
Les paramètres principaux sont le dossier d'entrée, le lineage BUSCO, le dossier de sortie
et le nombre minimal de gènes par chromosome. Le script dotplot.py produit les scores
de synténie ainsi que des figures PNG et HTML pour les paires de génomes comparées.
