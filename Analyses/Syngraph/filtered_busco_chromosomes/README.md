# Filtered Chromosome BUSCO TSVs for Syngraph

## Purpose & Context
The files in this directory have been renamed from their raw NCBI/ENA assembly accession prefixes to clean binomial species names. This standardization is required to ensure an **exact 1:1 name match** against the leaf node labels in the Newick phylogenetic tree during the `syngraph infer` stage.
